# Submission checklist (deadline: 30 October 2026) - built from the NISR webinar slides
## Eligibility
- [ ] Team of exactly 2 students, at least 1 Rwandan citizen; both have student card / official document
- [ ] Official challenge/track statement read; our project matches it word for word
## Repository (public GitHub) - at least these 4 items
- [ ] README.md: data used, what it communicates, how users interact (template provided)
- [ ] app.py (+ scripts) runs on any machine; requirements.txt pinned and tested in a fresh venv
- [ ] demo/demo.webm or .gif: screen recording on a computer (NOT phone), max 3 minutes
- [ ] data/ with processed dataset(s) + link to original data (note if too large)
## Deployed app
- [ ] Public link, opens without login, works from a phone and another network
- [ ] Cold-start tested (first load < ~30 s), no error on any dropdown combination
## Judging criteria -> evidence
1. Problem & relevance (NST2 / Vision 2050): README section 1 + first 20 s of video
2. Data use & methodology: real NISR data, preprocessing described, MAE/R2 on real data
3. Tangible impact: named users (cooperatives, MINAGRI/NAEB), concrete decision the app supports
4. Tech innovation: ML + optimisation + map, explained simply
5. Usability & design: bilingual, clear charts, functionality over decoration
## Integrity
- [ ] No simulated number is presented as real; every claim has a source
- [ ] Originality declaration filled in; we can explain every line of code
